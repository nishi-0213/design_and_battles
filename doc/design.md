# 設計＆戦闘ゲーム 設計書

## 目的

機体などを設計し、戦闘するゲームを開発する。
具体的なゲームルール、設計対象、戦闘方式は今後の会話で決める。

## 技術構成

- 描画: PixiJS 8
- 言語: JavaScript（将来 TypeScript の採用も検討可能）
- シェーダー: GLSL
- 描画効果: pixi-filters
- 描画バックエンド: WebGL

## 現在の実装

`Main.js` をエントリーポイントとして用意した。

- `main()` で PixiJS の Application を初期化する。
- 画面サイズに合わせて描画領域を変更する。
- ウィンドウ全体に HULL SIZE モニターを表示する。
- 機体・補助線を PixiJS、固定タブと小ウィンドウを HTML/CSS で描画する。
- 戻り値の `destroy()` で描画リソースを破棄する。

以前の描画確認用の仮の機体は取り外した。
独自 GLSL シェーダーは未追加。

## 機体の設計

### 確定事項

- PNG のドット絵風ブロックを重ねて機体を構成する。
- 「HULL SIZE」モニターはウィンドウ全体を占める。ブラウザーの Fullscreen API による全画面切替ではない。
- WASD でカメラを上下左右に移動し、マウスホイールで拡大縮小する。
- 左側に HULL / ARMOR / ENGINE / FUEL / GUN / AMMO / CABIN / PLANE / MISSILE の順で同じ幅のボタンを並べる。
- 各ボタンへのマウスオーバーで、その右側に小ウィンドウを表示する。

### 現在の表示の土台

- `HullMonitor.js` は全画面グリッドと機体用 `shipLayer`、カメラを管理する。
- `Main.js` は WASD の押下状態、ホイール、リサイズと破棄を管理する。
- `DesignControls.js` と `design.css` は左側の固定ボタンと小ウィンドウを管理する。
- WASD はカメラを移動する（W: 上、A: 左、S: 下、D: 右）。フォーカスを失った際に押下状態をリセットする。
- ホイールを上に回すと拡大、下に回すと縮小する。ポインター位置を基準に倍率を変える。
- 現在の倍率範囲は 25%〜400%。移動速度・倍率範囲・24 間隔の補助線は暫定的な表示設定。
- ボタンと小ウィンドウはカメラの移動・倍率の影響を受けない。
- 小ウィンドウへポインターを移しても表示を維持する。キーボードフォーカスでも開く。
- 小ウィンドウにはカテゴリ名と未登録案内を表示する。実素材の一覧は未実装。
- 空の機体エリアでも移動を確認できるよう、原点の縦横軸を表示する。

## 起動と公開

- Vite を開発サーバーとビルドに使用する。
- `index.html` → `bootstrap.js` → `Main.js` の順に起動する。
- Node.js 24 を推奨する。`npm ci` で依存関係を導入し、`npm run dev` で起動する。
- `npm run build` で `dist/` に静的ファイルを生成する。
- GitHub Pages 用の Actions を用意する。公開にはリポジトリの Pages の Source を GitHub Actions に設定する必要がある。
- インストール、本番ビルド、Chromium（ソフトウェア WebGL）での機体描画と画面リサイズを確認済み。
- GitHub Pages への公開と公開先での動作は未確認。
