# 設計＆戦闘

PixiJS 8 と JavaScript、GLSL、pixi-filters を使ったゲーム。
現在は全画面の DESIGN モニターに機体を配置する土台です。
WASD で移動、マウスホイールで拡大縮小できます。
左側のカテゴリボタンにマウスを重ねると右側に小ウィンドウが開きます。
HULL・ARMOR・ENGINE 内のパーツを選択すると半透明プレビューが表示されます。
グリッドをクリックして配置し、R で90度回転、Esc で選択解除できます。
現在はHULL同士、ARMOR同士、HULLとARMORの重なりは禁止です。
ENGINEは指定HULLに完全一致する位置だけに取り付けられます。
RD-90/RD-130は横1×縦2で、1x2 HULLに一致させるか、2x2 HULLの左右に1個または2個置けます。
90度回転した場合は2x2 HULLの上下に置けます。
RD-22-4は横2×縦4で、縦並びの2x2 HULL 2個が必要です（90度回転時は横並び）。
S-12は2x2 HULL 1個に一致させます。
固定式ロケットはフレームの背面に表示し、マウスオーバーで30度・3マスの赤い噴射範囲を表示します。
この範囲にブロックがあるとSAVEできません。
画像は1マス64pxで、複数マスのパーツも実寸解像度です。
今後のカテゴリは組み合わせごとに重なりルールを定義します。
DELで削除モードに入り、クリックしたブロックを削除します。Escで解除できます。
MASSは配置済みパーツの仮重量合計です（現状は1マス相当を1）。手持ちをEscで解除してから配置済みパーツをクリックすると、取り外して持ち直せます。

中央の2×2 BRIDGEは移動・削除できません。
SAVEするには全ブロックをBRIDGEへ辺で接続してください。他ブロック経由の接続も有効です。
角だけの接触は接続になりません。警告は画面下に表示します。

## 機体を保存する

右上の SHIP NAME に名前を入力して SAVE を押してください。
ブラウザー内に保存し、同時に `.ship.json` をダウンロードします。
最後に保存した機体はページを再読み込みすると自動復元します。同名の保存は更新になります。
取り外して持っているパーツは、配置するかEscで削除してから保存してください。

ダウンロードしたファイルは、プロジェクトの `ships/` フォルダで保管することを推奨します。
ブラウザーからこのフォルダへの直接保存はできないため、ダウンロード後に移してください。
ブラウザーデータの削除で内部保存は失われます。JSONをバックアップにしてください。
SAVE下のLOADを押すと、保存機体一覧が開きます。
機体名をクリックすると読み込みます。一覧の外をクリックすると閉じます。
JSONファイルの読み込みは今後追加します。

## 手元で試す

Node.js 24 を推奨します。

```sh
npm ci
npm run dev
```

ターミナルに表示される URL を WebGL 対応ブラウザーで開いてください。

## ビルド

```sh
npm run build
npm run preview
```

## GitHub Pages

リポジトリの Settings → Pages → Build and deployment の Source を
**GitHub Actions** に設定してください。
`main` への push または Actions の「Deploy to GitHub Pages」の手動実行で公開します。
公開 URL は成功した deployment の出力で確認できます。

仕様と未決事項は [doc/design.md](doc/design.md) に保存します。

FUELタブから灰青色の1x2タンク（燃料100）、白色の2x2タンク（燃料200）を配置できます。1x2はHULL 1x2、2x2はHULL 2x2に完全一致させて取り付けます。他装備との重なりは禁止です。上部のFUELは燃料総量、THRUSTは全エンジンの合計推力を表示します。値はバランス調整前の仮値です。

GUNタブに7種類の2x2艦砲を追加しました。単一の2x2 HULLに完全一致させて配置します。Rで90度回転できます。砲と他装備の重なりは禁止です。
